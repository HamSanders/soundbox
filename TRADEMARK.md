# Mirli trademark policy

Mirli's code is MIT licensed, and you can use it, change it, fork it and sell
it under that licence. The MIT licence covers copyright in the code. It doesn't
give you the right to use the Mirli name or logo. This page says how you can.

The goal is simple: when someone sees "Mirli", they should be getting the real
thing from this project, not a modified copy they can't tell apart from it.

## What this covers

- The name **Mirli**, in any font or styling.
- The Mirli logo and app icon (the "M" brand mark and the icons in
  `src-tauri/icons/`).

We call these "the marks" below. They're trademarks of the Mirli project
maintainer.

## Fine without asking

- **Talking about Mirli.** Articles, reviews, videos, tutorials, talks, course
  material and social posts can use the name, and the logo to illustrate what
  you're talking about.
- **Saying your work is compatible.** "A Godot plugin for Mirli", "works with
  Mirli", "Mirli preset pack" and "made with Mirli" are all fine, as long as
  they're true.
- **Passing on official releases unchanged.** You can share or mirror an
  unmodified Mirli release under its own name, with its own icon.
- **Building it yourself.** Personal and internal builds, with or without your
  own changes, can keep the name, as long as you don't distribute them to
  other people.
- **Packaging for a distribution.** Linux distributions and package managers
  can ship Mirli under its name with small changes needed to make it build and
  run on their platform, such as paths, dependency versions and security
  patches. Bigger changes count as a fork.
- **Community spaces.** Non-commercial user groups, forums, chats and meetups
  can use the name, provided they don't present themselves as official.

## Forks need their own name

If you distribute a modified version, give it a different name and a different
icon. You can describe where it came from, for example "Foo, a fork of Mirli"
or "based on Mirli", in the description, readme or about box.

Please don't choose a name that's easy to confuse with Mirli, such as
"Mirli Pro", "MirliX", "OpenMirli" or a near-spelling.

## Hosted services

You can run Mirli's code as a service; the MIT licence allows it. Don't call
the service Mirli, don't use the logo, and don't suggest it's run or endorsed
by this project. You can say it "runs on Mirli's open-source code".

## Ask first

These need written permission from the maintainer:

- Using the marks in a product, service or company name, other than the
  compatibility wording above.
- Using the marks in a domain name, app store listing, package name or social
  media handle that could be taken for an official one.
- Selling merchandise with the marks.
- Anything that suggests this project sponsors, certifies or endorses you.

## How to use the marks well

- Write the name as "Mirli": one word, capital M.
- Don't alter the logo apart from scaling it, and don't mix it into your own
  logo.
- You may add ™ after the name. (Use ® only after the mark is registered; it
  isn't yet.)

## Questions

Not sure whether your use is fine? Open an issue or email hello@mirli.app and
ask. The answer is usually yes.

This policy is based on the principles of the
[Model Trademark Guidelines](https://www.modeltrademarkguidelines.org/). It
may change as the project grows; the version in this repository is the current
one.
